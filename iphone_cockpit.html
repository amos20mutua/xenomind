Apple / iOS Shortcuts

  1. Xenomind - Reminder: receive a JSON text request; branch on create, list, or complete. Use Apple Reminders actions.
  2. Xenomind - Library: branch on photos, files, or organize; use iOS selection actions and require confirmation before changes or sharing.
  3. Xenomind - Home: match the requested scene and run it with your Home permissions. HomeKit is iOS-only in this version.
  4. Xenomind - Chain: process the payload's steps in order. Add your own Focus, Home, Reminders, and picker actions; iOS may still ask for permission or confirmation.

Enable receiving Text input. Use Get Dictionary from Input to parse the JSON; shortcut names must match the fields below. A returned handoff only confirms the Shortcut returned to this page.

Shortcut names

Names are saved only in this browser. The page never reads your reminders, library, or Home data.

Android / Native companion

Import the project from the android folder into Android Studio, build, and install it. The source handles local reminders and the Android photo/file picker; HomeKit is deliberately unavailable. This source has not yet been built or verified on a device.
